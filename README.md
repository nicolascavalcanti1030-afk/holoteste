# 🌸 Hololive Fan Project Web Application

Uma aplicação web interativa desenvolvida com **HTML5, CSS3 e JavaScript** voltada para a exibição de conteúdos, perfis e mídias das VTubers da agência **Hololive**, organizados por suas respectivas ramificações regionais (**JP, EN e ID**).

Este projeto foi criado como parte de estudos práticos para navegação multi-páginas no front-end e estilização temática responsiva.

##  Funcionalidades e Destaques

- **Navegação Multi-Páginas:** Estruturação de rotas estáticas separadas para cada divisão da Hololive (Japão, English e Indonésia).
- **Galeria de Mídias/Imagens:** Pasta dedicada (`holophoto`) para armazenar artes e avatares exibidos nas páginas.
- **Interatividade Front-End:** Manipulação de eventos e dinamismo de interface via `script.js`.
- **Layout Temático:** Estilização dedicada (`style.css`) adaptada à identidade visual do projeto.

```text
